# Phased Intelligence Website

Professional responsive website for **Phased Intelligence**, a mobile technology company.

## Included

- Responsive homepage
- Smartphone catalog with sample pricing
- Premium and value filters
- Accessories section
- Interactive cart counter
- Company/about section
- Newsletter form
- Mobile navigation
- GitHub Pages ready

## Files

- `index.html`
- `styles.css`
- `script.js`

## Publish with GitHub Pages

Upload the files to the root of your GitHub repository.

Then open:

**Settings → Pages → Deploy from a branch → main / root → Save**

After GitHub finishes publishing, your website will be available through your GitHub Pages URL.

## Note

The products, model names, and prices included in this demo are fictional placeholders and can be replaced with your actual inventory.
